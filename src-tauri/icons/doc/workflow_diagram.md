# Icon workflow

This folder has static image assets and no classes or internal workflow, so a class diagram would be misleading. [tauri.conf.json](../../tauri.conf.json) references [icon.ico](../icon.ico) for the direct build; [Build-Msix.ps1](../../../scripts/Build-Msix.ps1) copies the three package PNGs into its staged MSIX. [main.rs](../../src/main.rs) reads the configured default icon for the tray at startup. Separately, [icon.svg](../icon.svg) is exported as [msix-store-300.png](../msix-store-300.png) and [msix-store-71.png](../msix-store-71.png) for manual Partner Center Store listing uploads. These listing files are not consumed at runtime.
