# Icon assets

[icon.ico](../icon.ico) is the Windows application icon containing multiple resolutions (16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256). [icon.svg](../icon.svg) is the vector master asset for TopClock. `msix-44.png`, `msix-50.png`, and `msix-150.png` are square PNGs rendered from the 256-pixel ICO image for the MSIX manifest. [msix-store-300.png](../msix-store-300.png) and [msix-store-71.png](../msix-store-71.png) are 300×300 and 71×71 Store listing uploads rendered directly from the SVG master; they are not staged into the MSIX. [tauri.conf.json](../../tauri.conf.json) includes `icon.ico` in the NSIS bundle, [Build-Msix.ps1](../../../scripts/Build-Msix.ps1) stages the package PNGs, and [main.rs](../../src/main.rs) uses the configured default icon for the tray. This folder contains assets rather than executable code. See the [parent architecture](../../doc/architecture.md).
