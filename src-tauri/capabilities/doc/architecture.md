# Capabilities architecture

[default.json](../default.json) is the Tauri capability for `main`, `menu`, `palette`, `settings`, and runtime `clock-*` windows. It includes core permissions plus frontend event emission, start-dragging, and window geometry access. [palette.json](../palette.json) grants hide permission only to the palette WebView. Geometry reads and writes let [src/main.js](../../../src/main.js) fit each transparent clock window to its rendered text and position it without display-edge limits; [src/settings.js](../../../src/settings.js) broadcasts previews to all clocks. The [palette page](../../../src/addons/palette/palette.js) hides on release; its native [palette module](../../src/addons/palette.rs) may briefly show an action error while maintaining click-through and nonactivation. Rust also hides on release and owns size and position. See the [parent architecture](../../doc/architecture.md) for the full package.

This folder is a configuration boundary: add permissions only when a frontend feature needs them. `main`, `menu`, `palette`, and `settings` are configured in [tauri.conf.json](../../tauri.conf.json); `clock-*` labels are created by [displays.rs](../../src/displays.rs). The schema path points to generated metadata in `gen/`; do not hand-edit generated schema files.
