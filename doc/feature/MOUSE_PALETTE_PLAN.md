# Mouse palette (TODO 5, Add-on 6)

Date: 2026-11-16. Status: implemented in source; automated frontend and Rust checks pass. Physical Windows input, mixed-DPI, and multi-display behavior still need review.

## Decision and behavior

The palette is a global interaction mode, so its on/off switch is in General rather than in the add-on instance catalog. Shortcuts stores its activation key. A new installation has the switch off and Alt preselected; the key can be Ctrl, Alt, Shift, or None. The enabled key must differ from the Interaction Modifier. None turns the palette off. Existing settings files gain defaults without an explicit migration.

Hold the key for 120 ms to show a transparent, click-through palette around the cursor. Move over a sector and release to run it; release in the center, beyond the third ring, or on a branch without a final choice to cancel. The native monitor hides the overlay on key release before the selected action finishes, and the center uses a short “Cancel” label. A mouse click, Escape, Tab, or another modifier cancels while the key is held. Moving back to the first ring changes the active add-on, and moving back to the center clears selection. At most three rings appear: first-level menu entries, actions or sections, then section choices. The first ring pages after six entries, with Back and More sectors so the 16-instance add-on limit does not make a single ring unreadable. Hover a page sector, return to the center, then choose on the new page. When more than eight add-on switches exist, the second ring uses numbered ranges and the third ring shows each range's switches. Disabled or selected choices cannot be run. Confirmation-required Timer and Progress choices open the existing clock-menu confirmation panel after release, including its saved warning preference; the native action still validates the request.

## Ownership

- [Native palette monitor](../../src-tauri/src/addons/palette.rs) polls the selected modifier, physical cursor, and monitor every 20 ms. It owns the hidden full-monitor WebView position, nonactivating/click-through styles, and open/move/release events. It cancels when the normal clock menu is open or another modifier/Tab is pressed. The existing clock monitor skips topmost recovery while the palette is visible.
- [Palette model](../../src/addons/palette/palette-model.js) derives a three-level tree from the [add-on host's](../../src/addons/controller.js) current menu entries and switches. It owns pagination and physical position hit testing; add-ons continue to own actions, labels, sections, and choices.
- [Palette page](../../src/addons/palette/palette.js) renders SVG sectors with DOM APIs, measures and scales labels to fit each sector, asks the host to revalidate and dispatch selected operations, and hides itself after release. A choice needing confirmation opens the [existing menu panel](../../src/menu.js) through a pending-choice request in [menu_window.rs](../../src-tauri/src/menu_window.rs). Selecting Settings toggles its visible state through a palette-only command that preserves its normal save-and-close path; Quit uses its existing command. [Settings](../../settings.html) exposes the General switch and Shortcuts key selector.
- [Rust settings validation](../../src-tauri/src/settings.rs) persists `palette_enabled` and `shortcuts.palette_key`, allowing only the three modifier keys or None and rejecting an enabled key equal to `interaction_modifier`. The [Tauri window config](../../src-tauri/tauri.conf.json), [capability](../../src-tauri/capabilities/default.json), and [Vite entry](../../vite.config.js) include the palette page.

The palette has no add-on instance, add-on session, new add-on action command, keyboard hook, network access, or independent action registry. Its palette-only error command briefly reveals failed actions while restoring mouse transparency. Native timer/counter/progress transactions remain the authority for action validity and persistence.

## Checks and limits

`npm run build`, `npm run test:frontend`, and the Rust tests with one test thread passed on 2026-11-16. The default parallel Rust run had one existing topmost test fail; that test passed alone and in the serial full run. No physical input or packaged build was checked. The user chose to keep the circle centered on the original cursor position, accepting that parts can be clipped by display edges. To retry, release the configured key while the cursor is in the center or another non-action area, move the cursor inward, then hold the key again. Alt, Ctrl, and Shift retain their normal behavior in other applications; the 120 ms delay and combination guard reduce incidental activation but do not reserve those keys. See the [frontend backlog](../../src/doc/backlog.md) for live acceptance.
